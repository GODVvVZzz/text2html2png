演示页：[present.html](./present.html)。素材均来自合成案例，HTML 源稿与生成脚本保留在仓库。网站公开可访问；用户自己的文字需要交给装好技能的 Agent。这里不提供在线自然语言生成服务。

## 小红书图文草稿

标题：把一段技术说明，变成能放进文档的图

正文：

我做了一个开源技能 text2html2png。把发布流程、系统分层或方案对比交给 Agent，它会整理成 JSON，再由本地渲染器生成图。

这组图展示的是仓库里的合成案例：发布计划从文字变成流程图。默认保留 HTML 和 JSON；需要图片时，明确说“同时导出 PNG”。以后改文案或主题，可以用 JSON 重新生成。

支持中英文，导出前会检查裁字、重叠和中文短标题换行。架构图目前适合分层总览，复杂节点连线有明确限制。

GitHub 搜索 GODVvVZzz/text2html2png，或打开案例站。欢迎拿自己的任务试一次，成功和失败都可以在 GitHub 的“首次试用反馈”里记录。

## 抖音录屏脚本

建议录一段完整的“自己的内容 → 产物”过程，再剪辑成短视频。可以先用演示页排练讲解；演示页是预生成案例，不能剪成模型实时生成的证据。

| 镜头 | 画面 | 讲解重点 |
|---|---|---|
| 开场 | 原始发布说明和最终图同屏 | “这段发布说明，可以直接整理成文档配图。” |
| 输入 | 在已安装技能的 Agent 中粘贴自己的描述 | 展示完整需求，包括是否要 PNG；避免只展示事后准备的 JSON |
| 生成 | 实际运行过程 | 如加速或跳剪，标明加速；不添加虚构的倒计时或耗时 |
| 检查 | 放大中文标题和流程顺序 | 检查事实、顺序与排版，不声称永不出错 |
| 修改 | 修改原文或 JSON 中的一处内容并重渲染 | 展示后续修改成本 |
| 结尾 | 三种文件与项目地址 | “开源免费；需要 Agent 和本地运行环境，来试试自己的任务。” |

[竖版封面](./media/douyin-cover.png)留出底部空间，具体裁切需按实际发布界面预览调整。无需在宣传文案中解释安装内部细节；安装页负责说明 Node、浏览器和字体要求。

## 可以说与需要证据再说

可以说：开源、本地渲染、中英文、HTML 和 JSON 可保留、PNG 按需导出、已有跨平台检查。

需要实测证据：一次成功率、节省多少时间、胜过某竞品、所有复杂架构都支持、用户规模或收益。仓库中的安装体积测量是单次受控样本，不是用户使用效果。
