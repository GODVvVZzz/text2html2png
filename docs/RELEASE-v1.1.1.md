v1.1.1 fixes a first-use edge case in the local playground: when a selected theme’s fonts are missing, both HTML preview and PNG export now stop with the exact setup command. PNG can no longer silently use fallback fonts after preview has reported the missing dependency.

Includes all v1.1 launch improvements: selective font installation, public bilingual gallery, 24-task evaluation recorder, first-use feedback, and a product walkthrough.
