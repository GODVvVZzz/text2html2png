Release workflow

From idea to production

Six explicit gates keep every change reviewable and safe.

01
🎯

Plan

Define scope and acceptance criteria. Gate: Scope ready.

02
🛠

Build

Implement the smallest complete change. Gate: Checks pass.

03
👀

Review

Validate correctness, clarity, and risk. Gate: Approved.

04
✅

Test

Exercise behavior in a safe environment. Gate: Verified.

05
🐤

Canary

Release narrowly and observe signals. Gate: Healthy.

06
🚀

Production

Expand confidently with rollback ready. Gate: Shipped.

Gate by gate

Every stage earns the next one — a change that fails a gate stays put until the gate passes.
