Release workflow

From idea to production

Six explicit gates keep every change reviewable and safe.

01
🎯

Plan

Set scope and acceptance criteria. Gate: Scope ready.

02
🛠

Build

Implement the smallest complete change. Gate: Checks pass.

03
👀

Review

Validate correctness, clarity, and risk. Gate: Clear.

04
✅

Test

Exercise real behavior safely. Gate: Pass.

05
🐤

Canary

Release narrowly and observe signals. Gate: Green.

06
🚀

Launch

Expand confidently with rollback ready. Gate: Live.

Gate by gate

Every stage earns the next one — a change that fails a gate stays put until the gate passes.
