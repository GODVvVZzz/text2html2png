开源路线图

通往插件 API 的六个里程碑

图表库的公开规划：从首次渲染到可扩展内核，2031–2033。

2031 Q2
📈

v0.1 首次渲染

折线与柱形标记直接从一串普通数字数组绘制，仅输出到单一画布目标，无交互，也无主题。

2031 Q4
📐

v0.4 比例尺与刻度

提供线性、时间与序数三种比例尺，刻度标签从数据范围自动推导，不再硬编码。

2032 Q1
🖱️

v0.7 交互层

悬停、提示框与范围选择一应俱全，均可通过键盘触达，并向屏幕阅读器播报。

2032 Q3
🔒

v1.0 稳定 API

语义化版本自此启用：标记、比例尺与主题的契约在 1.x 内冻结。

2033 Q1
📄

v1.4 服务端渲染

无需浏览器即可渲染为静态 SVG，用于文档与邮件。

2033 Q3
🧩

v2.0 插件 API

标记、比例尺与主题可作为独立软件包发布，核心不再随每一种新图表而继续膨胀。

路线图说明

季度是目标而非承诺：范围调整优先于日期变动，每个里程碑都从 main 分支发布。
